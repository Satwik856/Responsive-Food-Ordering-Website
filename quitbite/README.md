# QuickBite — Responsive Food Ordering Website

## Files
- `index.html` — semantic page structure and small mobile navigation script.
- `style.css` — mobile-first styling using Flexbox, CSS Grid, media queries and a container query.

## Run in VS Code
1. Extract the ZIP file.
2. Open the `food_ordering_responsive` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Resize the browser or use Developer Tools → device toolbar to inspect mobile, tablet and desktop layouts.

## Responsive behaviour
- Mobile: one restaurant card per row; navigation opens with the menu button.
- Tablet (600px and above): two restaurant cards per row; full navigation appears.
- Desktop (900px and above): three restaurant cards per row.
- Each restaurant card uses a CSS container query to adjust its metadata layout when the card is narrow.

## GitHub Pull Request
A pull request must be created in your own GitHub repository:
1. Create a repository and upload these files to a feature branch (for example `feature/responsive-food-layout`).
2. Push the branch to GitHub.
3. Open the repository and choose **Compare & pull request**.
4. Add a title such as `Add responsive food ordering layout` and create the pull request.
